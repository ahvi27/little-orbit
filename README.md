# Little Orbit ✳

A responsive, space-themed website for curious minds. Explore imaginary worlds and discover your next escape with a random destination generator.

## Features

- Responsive layout for mobile and desktop
- Animated planet built with CSS
- Random destination generator
- Accessible navigation and live destination announcements
- Reduced-motion support
- No dependencies or build tools required

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repository:

    git clone https://github.com/YOUR-USERNAME/little-orbit.git
    cd little-orbit

Open `index.html` in your browser.

Replace `YOUR-USERNAME` with your GitHub username.

## Project Structure

    little-orbit/
    ├── index.html
    └── README.md

## Customization

Edit `index.html` to make it your own:

- Change colors using the CSS variables in `:root`.
- Update the titles and card descriptions in the HTML.
- Add destinations to the `escapes` array in the script.
- Adjust the planet and ring styles in the CSS.

## Deploy with GitHub Pages

1. Push the files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch and the **/ (root)** folder.
5. Click **Save**.

GitHub will display your website URL once deployment finishes.
